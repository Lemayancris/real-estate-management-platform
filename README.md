# Real Estate Management Platform

A modern real-estate platform for the Kenyan market, built as a frontend foundation for property sales, rental management, and admin operations.

## Stack

- Next.js 14
- TypeScript
- Tailwind CSS
- Responsive UI for public and admin experiences

## Features included

- Public real-estate landing page
- Property listing and search experience
- Property details page with specs, amenities, and pricing
- Admin dashboard with KPI cards and analytics layout
- Kenyan-market-focused design language and content

## Getting started

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Project structure

- `app/` — Next.js app routes
- `components/` — reusable UI components
- `lib/` — mock data and shared definitions

## Notes

This repository currently focuses on the frontend foundation. The backend and database layers will be added in subsequent phases.
